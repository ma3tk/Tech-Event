## アンチパターン

- ❌ CTA ラベルに「参加」のような動詞 1 単語だけ → ✅ 「参加申込」「補欠登録」のように動詞 + 名詞
- ❌ プライマリ CTA を 1 画面に 3 つ以上 → ✅ 主要 CTA は 1 画面 1 つに絞る
- ❌ destructive を CTA に使う → ✅ 破壊的でなければ default / secondary
- ❌ disabled で説明なし → ✅ tooltip で「○○の理由で操作できません」を補う
