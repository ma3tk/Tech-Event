## status × CTA Button の対応

8 状態それぞれに対応する Button variant が決まっている (catalog 「2. UI 表現の一貫性」表)。

- `upcoming` → `disabled` "公開前"
- `open` → `default` "参加申込"
- `full` → `disabled` "満員"
- `waitlist` → `secondary` "補欠登録"
- `closed` → `disabled` "申込終了"
- `ongoing` → `link` "会場へ"
- `ended` → `ghost` "アーカイブを見る"
- `cancelled` → `disabled` "中止"

## アンチパターン

- 色だけで status を伝える (色覚特性に配慮しない) → 必ずテキスト併記
- `full` 状態で primary CTA を出したまま `disabled` にしない → 押しても何も起きないボタンは UX 悪化
- `waitlist` で `default` variant を使う → 補欠は補助操作なので `secondary`
- status 遷移時に Toast を出さない → P1 のような「予定確定派」は通知に依存する
