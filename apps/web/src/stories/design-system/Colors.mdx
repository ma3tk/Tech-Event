<Title>Colors</Title>
<Subtitle>Primitive スケール → Semantic alias → WCAG AA 準拠まで</Subtitle>

カラーは「色相 × 50〜950 の段階」(primitive) を持ち、それを意味のある名前 (semantic) にマッピングしています。
コンポーネントからは **semantic 名 (例: `bg-brand-orange`, `text-foreground`)** のみを使用してください。

すべての semantic ペアは axe-core により **WCAG AA (4.5:1) 以上** を満たすことが CI で検証されています。

---

## 3. Tailwind クラス対応表

semantic 名は `globals.css` の `@theme inline` 経由で以下の Tailwind ユーティリティを生成します。
**コンポーネントの実装ではこれらを使うこと**:

| 用途 | クラス例 |
| --- | --- |
| ページ背景 | `bg-background` |
| カード面 | `bg-surface` |
| muted 面 | `bg-surface-muted` |
| 本文 | `text-foreground` |
| 補助テキスト | `text-muted-foreground` |
| プレースホルダ | `text-muted` |
| 区切り線 | `border-border` / `border-border-strong` |
| ブランド CTA | `bg-brand-orange hover:bg-brand-orange-hover text-brand-foreground` |
| 薄ブランド | `bg-brand-orange-soft text-brand-orange-strong` |
| 強アクション | `bg-brand-red hover:bg-brand-red-hover` |
| リンク | `text-link hover:text-link-hover hover:underline` |
| ステータス | `bg-status-{open\|full\|waitlist\|closed\|cancelled\|ended\|upcoming\|ongoing}-bg text-status-{...}-fg` |
