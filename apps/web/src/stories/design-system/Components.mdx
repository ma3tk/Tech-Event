<Subtitle>UI primitives 21 個 / Composite components 17 個</Subtitle>

`tech-event` は 2 階層のコンポーネント構成です:

1. **UI primitives** (`src/components/ui/`) — shadcn 系の汎用部品。Radix UI ベース。Tailwind トークンに直接依存。
2. **Composite components** (`src/components/`) — ドメイン特化部品。primitives を組み合わせて構成。

各コンポーネントには Story が用意されており、Storybook サイドバーの **UI/** または **Components/** カテゴリから参照できます。

## 4. 命名規約

| 対象 | 規約 | 例 |
| --- | --- | --- |
| コンポーネントファイル | `PascalCase.tsx` | `EventCard.tsx` |
| primitives ファイル | `kebab-case.tsx` | `dropdown-menu.tsx` |
| コンポーネント関数 | `PascalCase` | `function EventCard(...)` |
| Props 型 | `PascalCaseProps` | `EventCardProps` |
| Props フィールド | `camelCase` | `isJoined`, `onJoinToggle` |
| CSS 変数 | `--kebab-case` | `--brand-orange` |
| ユーティリティ関数 | `camelCase` | `computePages` |
| 列挙的な定数 | `UPPER_SNAKE_CASE` | `STATUS_CONFIG` |
