<Title>Dark Mode</Title>
<Subtitle>data-theme 属性ベースの 3 モード切替 (light / dark / system)</Subtitle>

`tech-event` は **`<html data-theme>` 属性** をスイッチに、light / dark / system の 3 モードに対応します。
切替の状態は `localStorage` に保存され、リロード後も保持されます。
`prefers-color-scheme` の変化にもリアクティブに追従します。

---

## 1. 仕組み

```
ユーザー操作
      ↓
ThemeProvider.setTheme("light" | "dark" | "system")
      ↓
localStorage[`tech-event:theme`] に保存
      ↓
<html data-theme="light"|"dark"> 属性を更新
      ↓
src/styles/themes/{light,dark}.css の :root[data-theme=…] ルールが適用
      ↓
@theme inline 経由で Tailwind ユーティリティの色が再評価
```

### 1.1 SSR / hydration mismatch を避ける設計

- サーバー側では `<html>` に `data-theme` を **付けない**。
- クライアント mount 後、`useEffect` で localStorage を読み、`data-theme` を初めて設定する。
- これにより SSR と初回 hydration の出力が完全一致するため、mismatch 警告が出ない。
- mount 前 (FOUC の隙間) のフォールバックは `dark.css` 末尾の
  `@media (prefers-color-scheme: dark) :root:not([data-theme="light"]):not([data-theme="dark"])` ルールで担保。

## 2. ThemeProvider の使い方

### 2.1 セットアップ (既に完了)

`src/app/layout.tsx` でルートにマウント済み:

```tsx
import { ThemeProvider } from "@/components/ThemeProvider";

export default function RootLayout({ children }) {
  return (
    <html lang="ja">
      <body>
        <ThemeProvider defaultTheme="system">{children}</ThemeProvider>
      </body>
    </html>
  );
}
```

### 2.2 任意のコンポーネントから切り替える

```tsx
"use client";

import { useTheme } from "@/components/ThemeProvider";

export function ThemeSwitch() {
  const { theme, resolvedTheme, setTheme } = useTheme();

  return (
    <div>
      <p>現在: {theme} (実際: {resolvedTheme})</p>
      <button onClick={() => setTheme("light")}>Light</button>
      <button onClick={() => setTheme("dark")}>Dark</button>
      <button onClick={() => setTheme("system")}>System</button>
    </div>
  );
}
```

### 2.3 API

| 公開値 | 型 | 説明 |
| --- | --- | --- |
| `theme` | `"light" \| "dark" \| "system"` | ユーザーが選んだ値 (`"system"` を含む) |
| `resolvedTheme` | `"light" \| "dark"` | 実際に適用されている値 (system は OS で解決済み) |
| `setTheme` | `(t: Theme) => void` | 切り替え関数。localStorage 保存 + `<html data-theme>` 反映 |

> Provider の外で `useTheme()` を呼ぶと安全側に倒して `light` を返します。
> Server Component やテストでの誤用でクラッシュさせない設計。

## 3. Storybook での切替

Storybook 側にもダークモード切替を導入する場合は、ツールバーから `data-theme` を切り替える decorator を追加します
(現状はトークン値の対比表示で確認)。

ライブで切り替えたい場合は **Components の各 Story を開き、Canvas 内で DevTools を使い**
`document.documentElement.setAttribute("data-theme", "dark")` を実行することでテスト可能です。

将来的に `@storybook/addon-themes` 等を追加すれば、ツールバーから常時切替えできるようになります。

## 6. 注意点

- **半透明色は禁止 (`bg-brand-orange/10` 等)** — 合成後のコントラストが落ち、axe-core 違反になりやすい。
  必ず `--brand-orange-soft` のような **明示的なトークン** を使う。
- 文字色は基本 `text-foreground` / `text-muted-foreground` を使い、`text-white` / `text-black` 直書きは避ける
  (dark テーマで反転しないため)。
- `border-gray-200` 等の Tailwind 標準色を直接使うのも禁止。`border-border` を使う。
- 画像の上に文字を重ねる場合は、画像にダークオーバーレイを追加して両テーマで読めるようにする。
