<Subtitle>tech-event で公式採用するアイコン一覧 / strokeWidth 1.5 / 14·16·20·24 px</Subtitle>

`tech-event` のアイコンはすべて [`lucide-react`](https://lucide.dev) から名前指定で import します。
**追加のアイコンライブラリの混在は禁止**。色は `currentColor` 継承、サイズは 14 / 16 / 20 / 24 px の 4 段階のみ使用。

ベース 50 種は § 1 〜 § 5 で網羅される共通カテゴリ。
§ 6 の **Extra (tech-event 固有 20 種)** は calendar / event / group / 配信 / 主催 ドメインに特化した拡張セット。

詳細な規約は `docs/icons.md` を参照。

採用基準:

- **calendar / event ドメイン (10)** — Luma 由来のカレンダーサブスクライブ / チケット / QR チェックイン / イベント統計に必要
- **group / コミュニケーション (5)** — グループ詳細 / ディスカッション / Magic Link / @メンション
- **配信 / 主催 (5)** — オンライン配信形式の明示 (camera / video / mic) と公開/限定の区別 (lock / unlock)

合計 70 種 = 推奨 50 + Extra 20。これ以上の追加は `docs/icons.md` § 7 への PR を必須とする。

## 7. 使い方

各セルの中の 4 つは左から **14px / 16px / 20px / 24px** のサイズサンプル。
すべて `strokeWidth={1.5}` (デザインシステム規約) で描画されています。

```tsx
import { Calendar } from "lucide-react";

// 16px がデフォルト、隣接するテキストの色を継承
<Calendar className="h-4 w-4" strokeWidth={1.5} aria-hidden="true" />
```

- 文字サイズに対するサイズ対応、用途別の規約、`aria-hidden` / `aria-label` の使い分けは
  `docs/icons.md` を参照してください。
- 50 種以外のアイコンを使う場合は、PR 上で `docs/icons.md` § 7 に追記してから採用すること
  (= 暗黙の追加禁止)。
