<Title>Typography</Title>
<Subtitle>フォントスケール xs〜4xl / weight 4 段 / line-height 4 段</Subtitle>

`tech-event` のタイポグラフィは `Noto Sans JP` + 日本語システムフォント (`Hiragino Kaku Gothic ProN`, `Yu Gothic UI`, `Meiryo`) のフォールバック構成です。
ウェイトは原則 **400 / 600 / 700** の 3 段のみ使い、500 は装飾アイコン用にのみ使用します。

## 3. Line-height

| トークン | 値 | 用途 |
| --- | --: | --- |
| `--line-height-tight` | 1.2 | 大型見出し (h1/h2) |
| `--line-height-snug` | 1.4 | カード内タイトル / h3 |
| `--line-height-normal` | 1.6 | 短い説明文 |
| `--line-height-relaxed` | 1.7 | 本文 (body デフォルト) |

<Unstyled>
  <div style={{ fontFamily: "system-ui, sans-serif", color: "#1a1a1a" }}>
    {[

      { name: "snug", lh: 1.4 },
      { name: "normal", lh: 1.6 },
      { name: "relaxed", lh: 1.7 },
    ].map((row) => (
      <div
        key={row.name}

        }}
      >
        <code style={{ fontSize: "11px", color: "#6b7280" }}>
          {row.name} ({row.lh})
        </code>
        <p style={{ margin: "6px 0 0", fontSize: "14px", lineHeight: row.lh }}>
          技術イベントは、エンジニア同士が学びを共有しキャリアを広げる場です。
          本デザインシステムは情報密度を優先しつつ、読み手の負担を抑える行間設計を目指しています。
          本文の標準は <code>relaxed (1.7)</code> ですが、見出しやカード内タイトルでは
          <code>tight</code>〜<code>snug</code> に切替えて密度を保ちます。

      </div>

  </div>
</Unstyled>

## 5. 連用クラス対応

`docs/design-system.md §3` の対応表を再掲します:

| 要素 | サイズ | 行間 | ウェイト | 用途 |
| --- | --- | --- | --- | --- |
| `h1` | 28px (`text-[28px]`) | 1.3 | 700 | ページ主見出し |
| `h2` | 22px (`text-[22px]`) | 1.35 | 700 | セクション見出し |
| `h3` | 18px (`text-lg`) | 1.4 | 700 | サブ見出し / カード内タイトル |
| `h4` | 16px (`text-base`) | 1.5 | 600 | フォームラベル / 小見出し |
| body | 14px (`text-sm`) | 1.7 | 400 | 本文 |
| meta | 12px (`text-xs`) | 1.5 | 400 | 補助テキスト・日時・件数 |

---

## 6. 規約まとめ

- 非標準サイズ (13px, 15px 等) は使わない。
- `font-medium (500)` は通知バッジ等の限定用途のみ。一般文には `regular` か `semibold` を使う。
- 本文の line-height は常に `relaxed (1.7)`、見出しは `tight`〜`snug`。
- 日本語と英数字が混在しても破綻しないよう、`Noto Sans JP` を先頭に置く。
