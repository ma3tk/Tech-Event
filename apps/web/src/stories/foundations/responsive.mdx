## 規約

- モバイル (`<640px`) ではタッチ領域 44×44px 確保
- コンテナ max-w 1280px (px-6 sm:px-8 lg:px-12)
- 主要ページは lg 以上でメイン + 右サイド 2 カラム (2:1〜3:1)
- スペーシングは 4 / 8 / 12 / 16 / 24 / 32 / 48 / 64 px のみ (任意値禁止)
- `word-break: keep-all` + `overflow-wrap: anywhere` で日本語の折返しを最適化

詳細は `docs/catalog/foundations/responsive.md`。
