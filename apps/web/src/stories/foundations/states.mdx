## 規約

- `:focus-visible` で常時可視のフォーカスリング (`outline 2px brand-orange offset 2px`)
- `disabled` は `opacity-50 pointer-events-none` + `aria-disabled="true"` 併記
- `loading` は spinner + `aria-busy="true"`、中身は不可視化せず CLS 防止
- `empty` は理由 + 次のアクションを必ず添える
- `error` は原因 + 対処 (retry など) を添える

詳細は `docs/catalog/foundations/states.md`。
