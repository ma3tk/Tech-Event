## 1. 目的
グループを **カード形式** で表示。`standard` / `sidebar` / `compact` の 3 variant。参加ボタン付き。

## 2. いつ使うか
- グループ一覧 (`/groups`)
- ユーザープロフィールの「所属グループ」
- イベント詳細サイドバーの「主催グループ」 (sidebar variant)
- 関連グループのコンパクト表示 (compact)

## 3. いつ使わないか
- グループ単独のヘッダー → 専用 hero
- 1 行のリスト → 別 component
