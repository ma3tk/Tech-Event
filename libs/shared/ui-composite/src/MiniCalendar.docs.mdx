## 1. 目的
サイドバー用の **ミニカレンダー**。開催日にドット表示でイベント有無を示す。`date-fns` ベース。

## 2. いつ使うか
- グループページのサイドバー
- ユーザープロフィールのサイドバー
- カレンダーページのナビ

## 3. いつ使わないか
- 大きなカレンダー UI → 別 component
- 日付選択 → Calendar (将来 atom 化予定)

## 4. アクセシビリティ

- `<table role="grid">` (date-fns 慣用)
- 開催日には `aria-label` を補強

## 5. 使用例

```tsx
<MiniCalendar
  eventDates={dates}
  onSelectDate={(d) => router.push(`/calendar?date=${d}`)}
/>
```
