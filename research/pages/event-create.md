# イベント作成 / 編集ページ

## 概要・目的

connpass におけるイベント作成 / 編集ページは、勉強会・カンファレンス・ハンズオン等のテック系イベントを作り、公開・募集・受付までを一気通貫で行うための最重要画面である。主催者向け機能群の中核をなし、本ページで設定された内容がそのままイベント詳細ページ、参加申し込み導線、参加者一覧、サブイベント、決済、出席管理、領収データ発行、API レスポンスなどすべての下流機能に流れていく。

主な目的は以下の通り。

- イベントの基本情報（タイトル / 説明 / 開催日時 / 会場）の入力
- 募集ロジック（参加枠 / 定員 / 抽選 or 先着 / 補欠枠 / 募集期間）の設計
- 公開状態（下書き / 公開）と公開範囲（一般 / グループメンバー限定）の管理
- 課金方式（無料 / 会場払い / 前払い PayPal）の設定
- 出席コード、参加者向け非公開情報、ハッシュタグ、画像など参加者導線の構築
- 管理者・発表者の追加とサブイベント連携

未ログインの状態では `https://connpass.com/event/create/` は基本的にログイン画面にリダイレクトされ、未公開のドラフトを含むイベント編集 UI 本体は閲覧できない。したがって本ドキュメントは、connpass のヘルプサイト（https://help.connpass.com/organizers/event-detail 等）と公開済みイベントページの構造から逆算した「想定スキーマ」として記述する。

## URL 構造

- 新規作成: `https://connpass.com/event/create/`
- 編集: `https://{group_subdomain}.connpass.com/event/{event_id}/edit/`
  - 例: `https://bpstudy.connpass.com/event/123456/edit/`
- 編集（管理 TOP 経由）: `https://connpass.com/event/{event_id}/edit/` も内部的に同様の編集 UI に到達する
- 編集タブ（推測）:
  - `/edit/basic/` — 基本情報
  - `/edit/participation/` — 参加枠・参加費・募集設定
  - `/edit/venue/` — 会場
  - `/edit/sub_event/` — サブイベント
  - `/edit/messages/` — 一斉送信メッセージ管理
  - `/edit/survey/` — アンケート
  - `/edit/presenters/` — 発表者
  - `/edit/admins/` — 管理者
- 公開 URL: `https://{group_subdomain}.connpass.com/event/{event_id}/`
- グループ未紐付け（個人イベント）の場合: `https://connpass.com/event/{event_id}/`

URL の `{event_id}` はイベント作成時に採番される 6 〜 7 桁程度の連番。グループ紐付け後はサブドメインが解決ドメインとして優先される。サブドメインはグループ作成時に確定し変更不可。

## ページレイアウト

イベント編集ページは「左サイドバーに編集セクション」、「中央メインに入力フォーム」、「右上に保存 / プレビュー / 公開ボタン」、「下部にサブイベント・関連イベント設定」を持つ典型的なダッシュボード型レイアウト。

```
┌────────────────────────────────────────────────────────────────────┐
│ Global Header: ロゴ / 検索 / 「イベント管理」 / ユーザーメニュー      │
├──────────────┬─────────────────────────────────────────────────────┤
│ 編集ナビ      │  ステータスバー: [下書き|公開済] [自動保存: HH:MM]    │
│ ・基本情報    │  ─────────────────────────────────────              │
│ ・参加枠      │  タイトル                                            │
│ ・会場        │  サブタイトル                                        │
│ ・説明        │  グループ選択                                        │
│ ・サブイベント │  主催者表示名                                        │
│ ・管理者      │  開始日時 / 終了日時                                 │
│ ・発表者      │  募集期間                                            │
│ ・アンケート  │  会場 / オンライン区分                               │
│ ・公開設定    │  説明（Markdown エディタ）                          │
│ ・統計        │  画像アップロード                                    │
│              │  ハッシュタグ                                       │
│              │  参加者への情報（非公開）                            │
│              │  出席コード                                         │
│              │  重複参加許可                                       │
├──────────────┴─────────────────────────────────────────────────────┤
│ アクションフッタ: [下書き保存] [プレビュー] [公開する]               │
└────────────────────────────────────────────────────────────────────┘
```

モバイルは編集ナビが折りたたみのアコーディオン、もしくはタブ型に切り替わる。

## フォーム項目（詳細）

### 1. 基本情報セクション

- **タイトル** *(必須)*
  - 単一行テキスト
  - クリックでインライン編集が可能（自動保存）
  - 100 文字程度の上限を想定。空文字は不可
  - 一覧カード、OGP、メール件名、カレンダーに使用
- **サブタイトル / キャッチコピー** *(任意)*
  - 単一行〜短文。説明本文より先に小さく表示
- **グループ** *(任意・一度確定後は変更不可)*
  - プルダウン: 自分が管理者になっているグループ + 「グループに所属させない」
  - グループを選択するとサブドメインが紐づく
- **主催者表示名** *(任意・初期値はユーザー名)*
  - 自由文字列。共催イベントでは「A 株式会社 × B 株式会社」のような記載可

### 2. 開催日時 / 募集期間

- **開始日時** *(必須)*
  - カレンダーピッカー + 30 分刻みのプルダウン
- **終了日時** *(必須)*
  - 同上、開始日時より後
- **募集開始日時** *(任意)*
  - 空欄なら公開と同時に募集開始
- **募集終了日時** *(任意)*
  - 空欄ならイベント開始直前
- **タイムゾーン**
  - 暗黙的に JST 固定（UI 上は表示なし）

### 3. 開催場所

- **会場検索 / 新規登録**
  - 既存会場プルダウン + 新規入力。会場マスタは主催者単位で再利用
- **住所** *(任意)*
  - 自動的に Google Maps へ問い合わせ、緯度経度に変換
- **「オンライン」フラグ**
  - 住所欄に「オンライン」と書くと地図表示が抑制される
  - URL（Zoom / YouTube 等）は参加者への情報に記載するのが慣例

### 4. 参加枠 / 募集ロジック

- **受付方法**: `connpass で受け付け` / `受け付けしない（告知のみ）` の二択
- **参加枠（複数可）**
  - 各枠の項目:
    - 枠名 (string, 必須) 例: 「一般」「学生」「LT 発表者」
    - 募集方式: `先着順` / `抽選`
    - 参加費: `無料` / `会場払い` / `前払い (PayPal)`
    - 料金 (税込, integer, 円)
    - 定員 (integer, 0 で無制限)
    - 補欠枠を許可するか (boolean)
    - 申込開始 / 終了 (任意, 個別設定可能)
    - 詳細説明 (string)
  - 既に申し込みが入っている枠は削除不可、定員減算も制限あり
  - 並び順をドラッグで変更可能
- **補欠枠（バッファ）**
  - 定員超過は自動で補欠化
  - キャンセル発生時に補欠から自動繰り上げ
- **抽選**
  - 募集締切後に抽選実行
  - 当落通知はメールで自動配信
- **重複参加許可**
  - 初期値 `true`
  - `false` の場合、同時間帯に別のイベントへの申し込みがあると申し込み拒否

### 5. 説明（リッチエディタ）

- Markdown 記法対応
  - 見出し / 太字 / リスト / リンク / 画像 / コードブロック / table
  - 文字色やサイズ指定もサポート
- ツールバー: 見出し / 太字 / リンク / 画像挿入 / プレビュー切替
- プレビューはタブ式（編集 / プレビュー）

### 6. 画像 / メディア

- **メイン画像**: 1 枚, 1MB 以下, PNG/JPG/GIF
  - 推奨アスペクト比: 16:9 程度
- 本文中の画像は別途 Markdown でアップロード

### 7. SNS / 拡散

- **ハッシュタグ**: `#` 抜きで 1 つ。X(Twitter) 共有時に自動付与

### 8. 参加者向け非公開情報

- **参加者への情報** (Markdown)
  - 参加確定状態のユーザーのみ閲覧可能
  - Zoom URL、会場入館コード、Slack 招待リンクなどに使用
- **出席コード**: 半角英数字 + `-_`、当日チェックインで使用

### 9. 管理者 / 発表者

- **管理者**: connpass ユーザーを ID で指定（複数可）
- **発表者 / 講師**: ラベル名変更可（「登壇者」「ファシリテーター」等）
  - 表示順 / 顔写真 / 自己紹介リンクは個別管理

### 10. 公開状態

- **下書き / 公開** トグル
- 参加者 0 名なら一度公開済みでも下書きへ戻せる
- 公開直後にメール通知（グループフォロワーへ）が走る

### 11. 有料イベント特有のフィールド

- **PayPal アカウント** *(必須・有料時)*: 主催者の PayPal メールアドレス
- **領収書情報**
  - 発行者名
  - 適格請求書登録番号
  - 所在地
- **キャンセル説明** *(必須)*
- **問い合わせ先** *(必須)*: メール等

### 12. アンケート

- 主催者が自由に質問項目を追加（テキスト / 単一選択 / 複数選択）
- 申込時に必須回答とするか任意かを選択

## 状態による出し分け

- **未公開 (draft)**: 「公開する」ボタン表示。参加申込導線なし
- **公開済 (open)** かつ募集中: 編集制限が一部かかる（参加枠削除不可など）
- **募集締切後**: 「再開する」ボタン、参加枠の編集制限が強化
- **終了 (closed)**: 「資料の投稿」「領収データ発行」セクションが表示
- **参加者 1 名以上**: 下書きに戻せない
- **有料設定**: PayPal アカウント確認バッジ、領収書設定セクションが追加
- **グループ未紐付け**: グループ管理者一覧などのセクションが非表示
- **管理者権限のみのユーザー**: 公開設定 / 削除のメニューが制限される

## インタラクション

- フィールドの blur や プルダウン変更で自動保存（差分 PATCH）
- タイトル / 説明はインライン編集
- カレンダーピッカーは月送り対応、終了日時は開始日時に合わせて自動初期化
- 参加枠の追加 / 削除 / 並び替え（ドラッグ）
- 「公開する」押下で確認モーダル → グループメンバー / フォロワーへ告知
- 「下書きに戻す」押下で参加者 0 名チェック → 不可なら拒否
- プレビューボタンで新規タブにイベント詳細ページの仮レンダリングを表示
- 「サブイベントを作成する」リンクから子イベント編集へ遷移
- 「複製して新規作成」ボタンで雛形コピー
- 削除はステータスを `cancelled` にする論理削除が中心

## 推測される API コール

サブドメインや内部 API は公開されていないが、参加者用 API v1 / v2 と編集 UI の挙動から、以下のような内部 REST or RPC が動いている想定。

- `POST /api/v1/event/` — イベント新規作成
- `PATCH /api/v1/event/{event_id}/` — 部分更新（自動保存）
- `GET /api/v1/event/{event_id}/` — 編集中イベント取得
- `POST /api/v1/event/{event_id}/publish/` — 公開
- `POST /api/v1/event/{event_id}/draft/` — 下書きに戻す
- `POST /api/v1/event/{event_id}/cancel/` — 中止 / 削除
- `POST /api/v1/event/{event_id}/ticket/` — 参加枠追加
- `PATCH /api/v1/event/{event_id}/ticket/{ticket_id}/` — 参加枠更新
- `DELETE /api/v1/event/{event_id}/ticket/{ticket_id}/` — 参加枠削除
- `POST /api/v1/event/{event_id}/sub_event/` — サブイベント生成
- `POST /api/v1/event/{event_id}/image/` — 画像アップロード
- `POST /api/v1/event/{event_id}/admin/` — 管理者追加
- `POST /api/v1/event/{event_id}/presenter/` — 発表者追加
- `GET /api/v1/venue/?q=...` — 会場サジェスト
- `GET /api/v1/user/?q=...` — ユーザーサジェスト
- 外部: Google Places / Maps Geocoding, PayPal OAuth, 画像 CDN への multipart upload

## 模倣実装する際の留意点

- **自動保存とバージョン管理**: 編集中の競合（複数管理者編集）を考慮し、楽観ロックや最終更新者表示が必要
- **参加者ありの不可逆制約**: 参加者が 1 名でも入った瞬間、削除や定員減を禁止するロジックを必須化
- **抽選 / 先着の切替制約**: 募集開始後は方式変更を禁止すべき
- **Markdown のサニタイズ**: 任意 HTML や script を埋め込まれないよう、サーバ側でも DOMPurify 相当でクリーニング
- **時間刻みの UI**: 30 分刻みのプルダウン + 任意分指定の両立を検討
- **タイムゾーン**: connpass は実質 JST 固定だが、国際イベントを許容するなら IANA タイムゾーンを保存
- **PayPal 連携**: 有料イベントでは PayPal の OAuth 連携 / ビジネスアカウント検証が必須。決済確定は webhook で非同期に確定
- **権限分離**: 管理者と発表者は権限が異なる。発表者は本人のセッション情報や資料のみ編集可能
- **重複参加チェック**: 同一ユーザーが同時間帯イベントに重複しないようカレンダーロジックを持つ
- **画像最適化**: 1MB 制限内に収めるためサーバ側で自動リサイズ / WebP 変換
- **API レート制限**: 自動保存が頻発するため debounce + サーバ側 rate limit
- **アクセシビリティ**: 編集 UI は管理者が長時間使うため、キーボード操作、スクリーンリーダー対応必須
- **下書きの URL リーク防止**: 下書き状態は管理者のみが見られるよう URL 推測不能なトークンまたは権限チェックを徹底
- **イベントテンプレート**: 同じシリーズの繰り返し（毎月の勉強会）を考慮し「複製」「テンプレ化」機能を初期段階から
- **下書きの自動破棄**: 長期間放置されたドラフトを自動アーカイブする仕組み
- **多言語対応**: 公開フォームを英語化するオプション（カンファレンス向け）
