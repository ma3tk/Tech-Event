<Title>High Contrast Mode</Title>
<Subtitle>WCAG AAA (7:1) を強制する第三のテーマ</Subtitle>

`tech-event` は light / dark の 2 モードに加えて、視力の弱いユーザーや高齢者、屋外で
スマホを使うユーザーのために **High Contrast モード** を提供しています。
これは light theme の semantic alias をさらにオーバーライドし、すべてのテキスト/背景の
コントラスト比を **WCAG AAA (7:1)** 以上まで引き上げる第三のテーマレイヤーです。

---

## 1. 有効化方法

### 1.1 ユーザー明示切替

ヘッダー右上の **テーマ切替ドロップダウン** から「High Contrast」を選ぶと、
`<html data-contrast="more">` が付与され、`tech-event:contrast` キーで
`localStorage` に保存されます (リロード後も維持)。

### 1.2 OS / ブラウザ設定追従

`@media (prefers-contrast: more)` をユーザーが OS / ブラウザで有効化している
場合 (Windows 「ハイコントラスト」、macOS 「コントラストを上げる」など) も
自動的に High Contrast が適用されます。

`[data-contrast="normal"]` を明示しているユーザーはこの自動追従から外れます
(「自分で明示的に通常コントラストを選んだ」状態を尊重)。

## 4. `prefers-contrast` メディアクエリ

CSS Working Draft で標準化された `prefers-contrast` メディア特性は、
ユーザーが OS / ブラウザレベルで「コントラスト強調」設定をしているかを検出します。
Safari 14.5+ / Chrome 96+ / Firefox 101+ がサポート。

```css
/* OS で「コントラスト強調」が有効なら自動で発動 */
@media (prefers-contrast: more) {
  :root:not([data-contrast="normal"]) {
    --foreground: #000000;
    --border: #000000;
    /* ... */
  }
}
```

`[data-contrast="normal"]` を明示しているユーザーは除外することで、
「自分で通常を選んだ」意図を尊重します。

## 5. 設計上の選択

### 5.1 影 (shadow) を消し border で elevation を表現

High Contrast 環境では shadow が見えにくい (背景が純白 / 純黒のいずれかになるため)。
代わりに `border: 2px solid #000000` でカードや popover の境界を明示しています。

### 5.2 リンク下線の強制

`color` だけで区別すると色覚特性ユーザーがリンクを見落とすため、
High Contrast モードでは **全 `<a>` 要素に `text-decoration: underline`** を強制します。

### 5.3 フォーカスリングを 3px に拡大

フォーカス可視性を担保するため、`focus-visible` の outline を 2px → 3px に強化、
offset も 2px → 3px に拡大します。
