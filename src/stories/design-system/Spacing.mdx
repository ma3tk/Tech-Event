<Title>Spacing</Title>
<Subtitle>4px 基底のスケール / 0〜24 を視覚化</Subtitle>

スペーシングは **4px ステップ** を基底とし、`spacing-0` 〜 `spacing-24` の 13 段階を用意しています。
非標準値 (10px、14px 等) の使用は禁止。情報密度が必要な場面では `py-2.5` (10px) までに留めてください。

## 5. 使い分けガイド

| 用途 | 推奨 spacing | 例 |
| --- | --- | --- |
| アイコンと隣接テキスト | `gap-1` (4px) / `gap-2` (8px) | 検索アイコン + プレースホルダ |
| インライン要素の間 | `gap-2` (8px) | バッジ + ラベル |
| カード内パディング (small) | `p-3` (12px) / `p-4` (16px) | EventListRow |
| カード内パディング (default) | `p-4` (16px) / `p-6` (24px) | EventCard |
| カード間 / セクション内 | `gap-4` (16px) / `gap-6` (24px) | EventTimeline 内の行間 |
| セクション間 (縦) | `space-y-8` (32px) 〜 `space-y-12` (48px) | ページ内セクション |
| ページ上下余白 | `py-12` (48px) / `py-16` (64px) | Hero エリア |
| フォーム要素間 | `space-y-4` (16px) / `space-y-6` (24px) | login / signup |
| 大型ヒーロー余白 | `py-20` (80px) / `py-24` (96px) | LP の縦余白 |

---

## 6. 規約

- パディング・マージン・ギャップで使う値は **必ずトークンスケールから選ぶ**。任意の `px` 直書きは禁止。
- 情報密度を上げたいときの `py-2.5` (10px) はエスケープハッチとして例外的に許容。
- `space-y-*` を使うときは、子要素が flex/inline-block でないことを確認 (空 div で順番崩れを防ぐ)。
- モバイル / デスクトップで余白を変えるときは `md:p-6` のようにブレークポイントで切替える (中央値の `p-5` を作らない)。
